# UI 버튼 가이드

## 크롤링 엔진 탭 - 컨트롤 패널

### 🎭 크롤링 (Main Button)
- **용도**: 전체 통합 파이프라인 실행
- **구현 상태**: ✅ 완료
- **동작**:
  - Stage 1: 리스트 페이지 크롤링
  - Stage 2: 상세 페이지 크롤링
  - Stage 3: 데이터 검증
  - Stage 4: DB 스냅샷
  - Stage 5: 데이터 저장
- **예상 소요 시간**: 크롤링 범위에 따라 다름

---

### 📊 범위 다시 계산
- **용도**: 사이트 상태를 다시 분석하여 크롤링 범위를 재계산
- **구현 상태**: ✅ 완료
- **동작**:
  - 사이트의 현재 총 페이지 수 확인
  - 로컬 DB의 현재 상태 분석
  - 사용자 설정(page_range_limit 등) 반영
  - 최적의 크롤링 범위 제안
- **사용 시나리오**:
  - 사이트에 새로운 제품이 추가되었을 때
  - 크롤링 전 최신 범위 확인
  - DB 상태 변경 후 재계산 필요 시

---

### 🏃 빠른 동기화 (Shallow Sync)
- **용도**: 전체 페이지의 좌표(page_id, index_in_page)만 빠르게 동기화
- **구현 상태**: ✅ 완료 (`start_shallow_sync` 백엔드 명령어 호출)
- **동작**:
  - 전체 페이지를 빠르게 스캔
  - products 테이블의 좌표 정보만 갱신
  - 상세 정보는 크롤링하지 않음
- **예상 소요 시간**: 5-8분
- **사용 시나리오**:
  - 좌표 정보만 필요할 때
  - 빠른 데이터 갱신이 필요할 때
  - 스마트 동기화 전 사전 동기화

---

### 🧠 스마트 동기화 (Smart Sync)
- **용도**: 얕은 크롤링 + 진단 + 누락 보완을 자동으로 수행
- **구현 상태**: ✅ 완료 (`start_smart_sync` 백엔드 명령어 호출)
- **동작**:
  - **Phase 1**: 빠른 동기화 (좌표 갱신)
  - **Phase 2**: 누락된 product_details 분석
  - **Phase 3**: 누락된 상세 정보만 선택적으로 크롤링
- **예상 소요 시간**: 8-12분
- **사용 시나리오**:
  - 완전한 데이터 동기화가 필요할 때
  - 누락된 제품 상세 정보 자동 보완
  - 정기적인 데이터 유지보수

---

### 📊 누락 분석 (Analyze Missing)
- **용도**: 누락된 product_details 확인 및 보고
- **구현 상태**: ✅ 완료 (`analyze_missing_details` 백엔드 명령어 호출)
- **동작**:
  - products와 product_details 테이블 비교
  - 누락된 제품 상세 정보 리스트 출력
  - 누락 제품의 URL, 제조사, 모델 정보 표시
- **사용 시나리오**:
  - 데이터 완전성 확인
  - 크롤링 후 품질 검증
  - 스마트 동기화 전 누락 현황 파악

---

### 수동 크롤링 (Manual Crawl)
- **용도**: 특정 페이지 범위를 직접 지정하여 크롤링
- **구현 상태**: ✅ 완료
- **동작**:
  - 입력 필드에 페이지 범위 지정 (예: 498-492,489,487-485)
  - 지정된 페이지만 크롤링 실행
  - 진단 결과 기반 자동 범위 설정 지원
- **입력 형식**:
  - 단일 페이지: `498`
  - 범위: `498-492` (역순으로 498부터 492까지)
  - 복합: `498-492,489,487-485`
- **사용 시나리오**:
  - 특정 페이지만 재크롤링
  - 진단에서 발견된 문제 페이지 수정
  - 테스트 목적의 소규모 크롤링

---

## Stage X: DB Pagination Diagnostics

### 진단 실행
- **용도**: 로컬 DB의 page_id/index_in_page 정합성 검사
- **구현 상태**: ✅ 완료
- **동작**:
  - 페이지별 제품 수 검증
  - 중복/누락/범위 초과 탐지
  - NULL 좌표 제품 확인
  - 페이지 시퀀스 갭 분석
- **결과**:
  - 이상 그룹 리스트
  - 누락된 페이지 범위
  - 추천 동기화 범위

### URL 중복 제거
- **용도**: 중복된 URL 레코드 정리
- **구현 상태**: ✅ 완료
- **동작**: 동일 URL의 중복 레코드 제거

### products→details 동기화
- **용도**: products.url 기준으로 product_details에 page_id/index_in_page/id 정합화
- **구현 상태**: ✅ 완료
- **동작**: 크롤링 없이 DB 내부 데이터 정합성 보장

### DB 연결 진단
- **용도**: DB 연결 상태 확인
- **구현 상태**: ✅ 완료
- **동작**: 풀 상태, SELECT 가능 여부 등 확인

## 버튼 사용 순서 권장

### 초기 설정 및 크롤링
1. **📊 범위 다시 계산** - 최신 범위 확인
2. **🎭 크롤링** - 전체 파이프라인 실행

### 정기 유지보수
1. **🏃 빠른 동기화** - 좌표 정보 갱신
2. **📊 누락 분석** - 누락 현황 파악
3. **🧠 스마트 동기화** - 누락 자동 보완

### 문제 해결
1. **진단 실행** (Stage X) - 문제 파악
2. **수동 크롤링** - 문제 페이지만 재크롤링
3. **products→details 동기화** - 데이터 정합화

---
